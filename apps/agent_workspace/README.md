# SenticRAG Support Agent Workspace (`apps/agent_workspace`)

Operational workspace tailored for **Customer Support (CSKH) Agents** in accordance with User Story [`US-AGENT-01`](file:///home/intern-tdkhuong/Desktop/Intership%20/SenticRAG%20%E2%80%94%20Retrieval-Augmented%20Aspect%20Sentiment%20&%20Feedback%20Intelligence%20Engine/docs/product/user-stories.md#2-us-agent-01--support-agent-receives-pre-triaged-ticket-with-grounded-draft).

## Key Features
1. **Pre-Triaged Context Card**: Displays automated aspect, sentiment, and severity tags alongside customer warranty eligibility.
2. **Grounded Resolution Draft**: AI-synthesized response draft grounded in retrieved evidence with clickable policy citations (`[POL-WARRANTY-2026]`).
3. **1-Click Policy Actions**: Instant dispatch of approved guidance, escalation routing to technical specialists, or replacement authorization.
4. **Collaborative Feedback Interface**: Correct misclassified aspect tags or edit response wording to continuously train the underlying active-learning pipeline.
